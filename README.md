# 13 Days Cyber Security Workshop

Organized and Conducted by **SJMIT College**

---

## 📌 Workshop Overview

The **13 Days Cyber Security Workshop** conducted by **SJMIT College** is an intensive, hands-on training program designed to equip students with practical cybersecurity knowledge, hands-on laboratory experience, essential defensive and offensive security principles, and industry-standard security tools.

This repository serves as a centralized, day-by-day archive of notes, command references, practical exercises, lab screenshots, and resources gathered throughout the workshop.

---

## 🎯 Objectives

- Build a strong foundational and practical understanding of cybersecurity concepts.
- Understand core networking protocols, system administration, and security architectures.
- Gain hands-on experience with standard industry security tools and command-line utilities.
- Perform structured lab exercises, vulnerability assessments, and practical tasks.
- Foster secure coding practices, digital hygiene, and threat mitigation strategies.

## 🛠️ Tools & Technologies Used

The workshop incorporates a wide variety of tools, operating environments, and utilities:

- **Operating Systems & Environments:** Linux / Kali Linux, Ubuntu, Windows Subsystem for Linux (WSL), Virtual Machines (VirtualBox / VMware).
- **Network Analysis & Reconnaissance:** Command-line network utilities, packet analyzers, and scanning tools.
- **Security Assessment & Auditing:** Vulnerability scanners, web security tools, and auditing utilities.
- **Scripting & Automation:** Shell scripting (Bash / PowerShell) and Python.

*(Specific tool names, versions, and scripts are documented inside each Day's `Commands/` and `Resources/` folders.)*

---

## 🧪 Practical Activities

Each day is structured with dedicated hands-on practical exercises:

1. **Notes (`Notes/`):** Detailed theoretical concepts, summaries, and architecture overviews.
2. **Commands (`Commands/`):** CLI commands, cheat sheets, syntax breakdowns, and execution steps.
3. **Practical (`Practical/`):** Lab writeups, scripts, exercises, and challenge solutions.
4. **Screenshots (`Screenshots/`):** Step-by-step visual proofs of completed lab exercises and command outputs.
5. **Resources (`Resources/`):** Reference links, presentation slides, documentation, and external reading materials.

---

## 📈 Workshop Outcomes

Upon completing the 13-day workshop, participants will have gained:

- Hands-on laboratory experience across key domains of cybersecurity.
- Proficiency in navigating Linux environments and executing security-focused command-line workflows.
- Practical knowledge of identifying, analyzing, and documenting security vulnerabilities.
- A structured portfolio of completed cybersecurity exercises, documentation, and proofs.
