# 13 Days Cyber Security Workshop

Organized and Conducted by **SJM Institute of Technology (SJMIT College)**

---

## 📌 Workshop Overview

The **13 Days Cyber Security Workshop** conducted by **SJMIT College** is an intensive, hands-on training program designed to equip students with practical cybersecurity knowledge, networking essentials, operating system security, cloud architectures, and defense mechanisms.

This repository serves as a centralized, professional documentation hub for the daily workshop topics, notes, commands, and exercises.
